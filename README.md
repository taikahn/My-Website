# Tai Kahn — Portfolio

Personal portfolio site built with **React** + **Vite**, deployed on **Cloudflare Workers**.

## Stack

- React 19
- Vite (+ `@cloudflare/vite-plugin`)
- Cloudflare Workers (Wrangler)

## Local dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

The Worker auto-deploys from `master` via Cloudflare's GitHub integration. To deploy manually:

```bash
npm run deploy
```
